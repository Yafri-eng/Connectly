Läuft diese Seite ausserhalb von Claude? API-Key eintragen

Innerhalb von Claude.ai wird das nicht gebraucht. Ausserhalb — lokal geöffnet oder selbst gehostet — braucht diese Seite einen eigenen Key von console.anthropic.com. Der Key bleibt nur im Speicher dieser Browser-Sitzung. Für einen produktiven Einsatz gehört er hinter einen eigenen Server statt direkt im Frontend, da er sonst im Netzwerk-Tab sichtbar ist.
